# Multi-Floor Parking Lot System

## Features

The console application supports multiple floors, BIKE/CAR/TRUCK vehicles,
slot allocation, tickets, hourly fees, exit, slot release, free-slot viewing,
duplicate validation, invalid-ticket validation, and occupancy display.

## Class Structure

`ParkingLot` contains `ParkingFloor` objects. Each floor contains
`ParkingSlot` objects. `ParkingLotServices` coordinates parking and exit.
`Ticket` stores the vehicle, floor, slot, entry time, and status.

## Design Patterns

The Strategy pattern is used by `FeeStrategy`/`DefaultFeeStrategy` and
`SlotAllocationStrategy`/`FirstAvailableSlotStrategy`. The service can receive
different pricing or allocation behavior without changing its main logic.

Vehicles are created directly with the simple `Bike`, `Car`, and `Truck`
classes.

## How to Run

```text
javac -d bin src\models\*.java src\services\*.java src\Main.java
java -cp bin Main
```

The simple functional tests can be run with:

```text
javac -cp bin -d bin test\ParkingLotTests.java
java -cp bin ParkingLotTests
```

## Validation

Active license numbers cannot be parked twice. A ticket must be the active
ticket generated by this service. Completed tickets cannot be reused. A
vehicle cannot be parked when no compatible slot is available.

## Test Cases

The functional test class covers bike, car, truck, duplicate parking, full
slots, invalid tickets, fee calculation, successful exit, slot release, and
repeated exit.
